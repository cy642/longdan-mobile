# 龙胆：逆命三国 · 手机版

宣传副标题：**重生之我在三国当赵子龙**。独立的手机浏览器试玩版，第一章「长坂逆命」沿用电脑版的角色、八方向动作、六个区域和剧情分支，专门设计横屏触控界面。

- [手机版仓库](https://github.com/cy642/longdan-mobile)
- [独立电脑版](https://cy642.github.io/longdan-game/)

## 手机怎么玩

用手机浏览器打开试玩地址，点击「踏入长坂」时会尝试进入全屏并锁定横屏；支持该能力的 Android 浏览器会自动横过来。iOS 普通浏览器通常不允许网页直接旋转，页面会提示横过手机；把网页添加到主屏幕后，`manifest.webmanifest` 会声明横屏全屏模式。首次加载需要下载角色图片，请等载入完成。无需登录或付费。

| 操作 | 触控方式 |
|---|---|
| 移动 | 左侧摇杆，支持慢走和任意方向 |
| 龙枪三式 | 按住右侧「出枪」连续攻击，优先朝向身边敌人 |
| 闪避 | 拖摇杆决定方向，同时点「闪避」；消耗16气力 |
| 横扫破阵 | 点「破阵」；消耗30气力，有冷却 |
| 青釭断势 | 夺得青釭剑、战意满后点「青釭」 |
| 回复体力 | 点左侧「行军药」，服药会被受击打断 |
| 救援 / 休整 / 前进 | 靠近目标，点屏幕下方出现的互动按钮 |
| 任务 / 路线 / 随军军令 | 右上角「军图」；军图暂停战斗 |
| 暂停 / 继续 | 右上角「暂停」 |

默认「初入战场」难度，更适合初次触控游玩；也可在标题选择「龙胆」。敌人出手前的红色区域会提示危险，观察起手、松枪闪避、趁收招反击。随军负责牵制，不能替玩家自行完成击杀。

支持同时移动和出枪。抬起一根手指不会清掉另一根手指的操作；失去触点、旋转屏幕、切后台和暂停时清除输入。竖屏显示横屏提示并暂停战斗；转回横屏后点「重返战场」继续。

全屏和方向锁定由浏览器安全策略决定，首次点击会触发一次最佳尝试；部分普通浏览器仍需手动横屏。加入主屏幕后，浏览器可按 manifest 以横屏全屏启动。

## 章节与保存

溃军山道 → 荒村小巷 → 破庙夺剑 → 井畔旧宅 → 粮道岔口 → 北桥决战。包括夏侯恩、张郃两场敌将战，以及医者救援、阿斗与糜夫人、焚粮改变弓阵等分支。

营火、区域入口、敌将入口和完成救援会保存。重试保留已完成的剧情。手机版使用 `longdan.mobile.changban.v1`，与电脑版保存键不同，不覆盖电脑版的存档。存档只保存在当前浏览器中，没有账号和跨设备云存档。换浏览器、清浏览数据或使用无痕模式，进度可能无法保留。

## 开发与部署

```powershell
node build.mjs
node verify.mjs
python -m http.server 8768 --bind 127.0.0.1
```

本机预览 `http://127.0.0.1:8768/`。生成的 `index.html` 内嵌样式和游戏脚本，六张角色图片保留在 `assets/`，方便浏览器分别缓存。部署时需要一起上传 `assets/`；单独复制 HTML 不包含图片。

GitHub Pages 使用 `main` 分支根目录，包含 `.nojekyll`。没有后端、外部 AI 请求、账号或联网对战。

- `mobile-controls.js`：摇杆、多触点输入和近距离瞄准。
- `game.js`：触控绑定、手机界面、镜头、音效和浏览器保存；保留键盘兼容，便于电脑浏览器预览。
- `campaign.js`、`stages.js`：战斗、敌将、救援分支和章节进度。
- `visuals.js`：与电脑版相同的八方向走动、蓄势和刺击，统一人物比例。
- `shell.html`、`styles.css`：横屏界面、拇指按钮和安全区域。

手机版限制画布像素比例、预绘地形分辨率和绘制帧率，并缓存角色图集；切换后台、旋转和画布表面恢复时会清理输入并重建画面，减少手机浏览器花屏或残留帧。首次加载和帧率仍取决于手机、浏览器和网络。当前步行和出枪主要是每方向两帧，后续可继续增加连续动作。

`verify.mjs` 覆盖生产战斗、章节分支、敌将二阶段、重试与存档，并验证同时移动和攻击、不同手指独立松开、摇杆死区与斜向归一化、输入清除、近距离瞄准、军图下达军令及图片部署完整性。

素材来源与提示词保留在 [ART-NOTES](assets/ART-NOTES.md) 和 [ATTACK-V3-NOTES](assets/ATTACK-V3-NOTES.md)。手机界面会使用浏览器尺寸检查；真实 iPhone / Android 的触屏手感和帧率仍需实机试玩。
